# Reference material — not published on the site

**Screenshots** (`IMG-*.jpg`) — the studio's Acuity booking page. The address,
hours, phone number, deposit terms, parking, late policy, colouring details and
salon policies on the live site were transcribed from these.

**`.avif` files** — assets from the Framer template used as a visual reference.
These are stock photography belonging to that template, not HBL's own work, so
they are deliberately **not used on the site**. Using them on a live commercial
site would be a licensing risk, and they don't show locs work.

Nothing in this folder is linked from any page. It's kept for reference only and
can be deleted at any time.
